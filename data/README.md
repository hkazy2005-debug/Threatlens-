# Synthetic / Demo Data

All data in this folder is **synthetic** — generated for demonstration and 
testing purposes only. It does not represent real network traffic, real 
users, or real security events from any actual organization.

Files:
- `firewall_events.csv` — simulated firewall allow/block logs
- `dns_events.csv` — simulated DNS query logs
- `edr_events.csv` — simulated endpoint detection events
